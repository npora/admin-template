# 独立展示模块

本目录集中保存展示内容，复用 `src/` 的布局、认证、权限、主题、多语言和公共组件。核心构建不导入这里的页面或示例数据；使用者接自己的后端时无需删除本目录。

| 目录或文件         | 用途                                           |
| ------------------ | ---------------------------------------------- |
| `index.ts`         | 演示静态路由、首页和可被动态路由引用的页面注册 |
| `pages/dashboard/` | 原美化首页、真实接口汇总和展示样式             |
| `pages/table/`     | 本地任务表格、筛选、排序、编辑、导出及独立数据 |
| `pages/form/`      | 分步表单、字段校验和按账号隔离的本地草稿       |
| `pages/download/`  | 本地文件下载示例                               |
| `pages/cache/`     | 页面缓存演示                                   |
| `api/`             | 展示首页的统计接口与 DTO                       |
| `utils/`           | 示例使用的 CSV 导出工具                        |
| `tests/`           | 演示控制器、数据模型与路由隔离测试             |

启动：`pnpm dev:demo`。构建：`pnpm build:demo`。测试：`pnpm run check:examples`。

展示模式使用真实 HTTP API，没有本地接口模拟。登录、系统管理和首页统计来自测试后端；表格任务与表单草稿是页面自身的数据示例，不是接口 Mock。测试后端仅供体验，接入实际业务应使用自己的服务。

既有后端的 `examples/table/index`、`examples/download/index` 等组件标识保持兼容；注册表将它们映射到本目录的页面。内部表单弹窗不作为路由入口。核心模式不接受这些示例组件标识，自有后端应使用正式 SQL 中的系统菜单或自己的页面。

新增演示页面放在 `pages/<名称>/index.vue`，静态入口在 `index.ts` 注册；动态入口仍由测试后端授权。`VITE_DEMO_ENABLED=true` 才加载本模块。目录不存在时核心模式照常工作，主动请求展示模式则明确报错。
