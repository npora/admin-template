# 数据库模型

`schema.sql` 定义 Npora Admin 的数据库契约 V1，面向 MySQL 8.0.16+。

| 表               | 职责                     |
| ---------------- | ------------------------ |
| `sys_user`       | 用户资料和账号状态       |
| `sys_department` | 部门层级                 |
| `sys_role`       | 角色                     |
| `sys_menu`       | 菜单、动态路由和按钮权限 |
| `sys_user_role`  | 用户与角色关联           |
| `sys_role_menu`  | 角色与菜单、按钮权限关联 |

该 SQL 是含 `DROP TABLE` 的初始化脚本，不是生产增量迁移。本次代码整理没有修改 SQL 或执行数据库操作；已有系统应另外管理版本化迁移。

数据库实体与接口 DTO 分开定义。前端接口以 `src/api/types` 为准；Mock 内部的表位于 `mock/rbac`，使用 SQL 列名和关联表；前端通过 `roleIds` 维护用户多角色，通过 `menuIds` 维护角色授权。部门提供树形维护页面、选择树和用户按下级部门筛选。后端实现应负责认证、接口授权、唯一性、字段校验及事务。
