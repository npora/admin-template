# 开发与环境配置

执行 `npm install`、`npm run dev` 开发，`npm run build` 构建，`npm run check` 验证。

| 文件               | 作用                     |
| ------------------ | ------------------------ |
| `.env`             | 所有模式共享的公共默认值 |
| `.env.development` | 开发模式默认值           |
| `.env.production`  | 生产模式默认值           |

同名变量优先使用进程环境，其次是当前模式文件，最后是 `.env`。开发配置修改后重启 Vite。

`VITE_API_URL` 用于 Vite 开发与本地预览代理，`VITE_API_PREFIX` 默认 `/api`。代理仅转发此前缀及其子路径，转发时去掉前缀并保留查询参数。生产服务应配置同源 API 转发。`VITE_` 开头的变量可能暴露给浏览器，禁止存放密钥。

多语言默认语言、启用开关、支持列表在 `src/config/i18n.ts`；Element Plus、Day.js 与页面日期格式同步切换。具体见 [多语言](i18n.md)。

纯净前端需要自己的后端才能登录，不在浏览器模拟认证。Worker 预设额外包含 `workers/api/`，运行方式见该目录说明。

## 本地偏好与缓存

点击页面右上角齿轮进入应用设置，可调整八种主题色、组件尺寸、菜单布局、顶部页签样式、灰色模式、色弱辅助和应用名称水印。偏好保存在当前浏览器。顶部和混合布局共用一条顶栏，窄屏回退侧栏。

“清空缓存”经确认后刷新当前页面，重新加载页签、页面和字典等运行数据。偏好和已保存草稿会保留，未保存的修改可能丢失。默认会话存储会保留登录，仅内存模式需重新登录。

顶部可按中英文名称或路由路径搜索当前账号可见的菜单，支持键盘操作。

用户、角色和字典的分页 CRUD 共用 `src/composables/useManagementTable.ts`；字典页面只补充缓存失效。用户专属选项和树形业务在对应页面中维护。包管理器自由选择，文档命令以 npm 为例。

新增页面参照 [完整业务开发流程](new-business-page.md)。管理编辑表单使用 `useFormSubmit`：初始化规范化快照，未变化直接关闭，防止重复提交与迟到校验写入。取消不刷新，实际保存成功由列表逻辑刷新一次。
