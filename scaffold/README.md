# 模板预设维护

核心页面只维护在 `src/`，演示页面只维护在 `examples/`。生成器通过目录筛选与少量覆盖文件组成项目，不执行下载模板中的脚本。

| 目录      | 用途                                                                         |
| --------- | ---------------------------------------------------------------------------- |
| `core/`   | 纯净 Vite 入口、空页面扩展入口、类型检查范围、依赖与锁文件快照、纯净使用说明 |
| `worker/` | 核心页面白名单、核心菜单 SQLite 种子和独立后端说明                           |

生成器默认 `starter`；`worker` 在相同核心上附加后端；`demo` 保留完整仓库的演示与展示实现。生成结果不包含本目录、仓库维护用的预设更新/验证脚本、本机资料、构建缓存和 Git 历史。

修改根目录依赖或核心命令后执行 `pnpm run update:presets`，同步 `core/package.json` 和裁剪后的锁文件。此命令仅在维护时执行，使用已缓存依赖离线更新锁文件；生成项目不需要执行它。生成器会拒绝依赖规格过期的快照。

涉及核心菜单或页面时，同步 `worker/` 中的种子与白名单；正式 MySQL SQL 在根目录 `database/mysql/`，其账号和密码算法由实际后端定义。Worker 的 SQLite 迁移只在 Worker 预设中使用，既有完整演示迁移保持兼容。

修改后运行：

```sh
pnpm run check:all
node scripts/check-presets.mjs ../create-nova-admin
```

后一个命令在临时目录生成并检查三个真实项目，包括前端类型、测试、生产构建、文档链接和 Worker 回归。需要先安装生成器自身依赖；生成器不会执行远程发布。
